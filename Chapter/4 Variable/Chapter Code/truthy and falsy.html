Truthy and Falsy

In JavaScript, values can be classified as either "truthy" or "falsy".

A truthy value is a value that evaluates to true in a boolean context, while a falsy value evaluates to false.

Here are some examples:

  • Truthy values: true, {}, [], 1, "non-empty string"
  • Falsy values: false, null, undefined, 0, "", NaN

You can use these values in conditional statements to control the flow of your program.
